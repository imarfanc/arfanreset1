Disk usage (uv)

Shows free space on / and ~, then the ten largest items in your home folder. It deletes nothing.

  • read only
  • needs uv
  • two levels deep
  • skips node_modules, .git, Library/Caches

1Copy, paste into Terminal, press Return

Uses uv from step 2 to run the Python scan with Rich. For system python3, use Disk usage (macOS).
