Step 2 of 5

Install CLI tools

One paste per tool. Each is independent, so pick the ones you want in any order. Open a new Terminal window when you finish.

  • no password
  • installs into your home folder
  • safe to rerun

1Deno

deno.com. Step 4 needs it. When the installer asks about your shell, either answer works.

deno1 line
curl -fsSL https://deno.land/install.sh | sh

2uv

docs.astral.sh/uv. Python and packages. Step 5, the disk scan and the version check below all run through it.

uv1 line
curl -LsSf https://astral.sh/uv/install.sh | sh

3Atuin

atuin.sh. Searchable shell history on Ctrl-R.

atuin1 line
curl --proto '=https' --tlsv1.2 -LsSf https://setup.atuin.sh | sh

4Claude Code

claude.ai/code. Run claude afterwards to sign in.

claude1 line
curl -fsSL https://claude.ai/install.sh | bash

5Codex

chatgpt.com/codex. Run codex afterwards to sign in.

codex1 line
curl -fsSL https://chatgpt.com/codex/install.sh | sh

6nvm and Node.js

nvm and nodejs.org. Installs nvm, loads it in this window, then installs Node 26 with npm.

7Bun

8OpenCode

9Check versions

Paste in a new Terminal window. One table shows each tool's path and version, or "not found". It also covers Xcode, the Command Line Tools, brew, perl and swift. Bash and zsh are included with their paths (like which bash and which zsh) and --version results. Expect Node 26.10.0 and npm 11.19.1.
