Install Command Line Tools

Apple's clang, git and make, straight from Software Update. You skip the "install developer tools?" dialog.

  • asks for your password
  • needs internet
  • safe to rerun
Start here
  1. Copy the script in step 1 and paste it into Terminal.
  2. Type your administrator password when it asks.
  3. Back in the app, open Command Line Tools and choose Check installation.

It worked if the script printed the developer tools path and the clang and git versions.

1Copy, paste into Terminal, press Return

It runs in its own zsh, so an error ends the script and leaves your window open.

install-clt.zsh55 lines
zsh <<'ZSH'ZSH

2Read the result

  • Already installed: it prints the xcode-select -p path and the clang and git versions. You're done.
  • Not installed: it picks the newest "Command Line Tools for Xcode" from softwareupdate -l and installs it with sudo.
  • Nothing in the catalog: it stops. Run xcode-select --install to get Apple's dialog instead.
Source: apps/26.9/script-runner1/data/scripts/setup/ in s7, with the output helpers inlined so it runs on an empty Mac.
