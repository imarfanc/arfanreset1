Install Command Line Tools

Apple's clang, git and make, straight from Software Update. You skip the "install developer tools?" dialog.

  • asks for your password
  • a few minutes
  • safe to rerun

1Copy, paste into Terminal, press Return

It runs in its own zsh, so an error ends the script and leaves your window open.

install-clt.zsh55 lines
zsh <<'ZSH'set -euo pipefail# Output helpers, inlined so this runs on a Mac without the repo.BOLD=$'\033[1m' DIM=$'\033[2m' GREEN=$'\033[32m' AMBER=$'\033[33m' RED=$'\033[31m' BLUE=$'\033[34m' RESET=$'\033[0m'heading() { printf '\n%s%s%s\n' "$BOLD" "$1" "$RESET"; }ok() { printf '  %s✓%s %s\n' "$GREEN" "$RESET" "$1"; }todo() { printf '  %s•%s %s\n' "$AMBER" "$RESET" "$1"; }fail() { printf '  %s✕%s %s\n' "$RED" "$RESET" "$1"; }info() { printf '  %s%s%s\n' "$DIM" "$1" "$RESET"; }suggest() { printf '\n  %s%s%s\n' "$BLUE" "$1" "$RESET"; }# ── Command Line Tools ──────────────────────────────────────────────────heading "Command Line Tools"if xcode-select -p >/dev/null 2>&1; then  ok "CLT already installed: $(xcode-select -p)"  info "$(clang --version 2>/dev/null | head -1)"  info "$(git --version 2>/dev/null)"else  # Trick the system into listing the CLT package  TRIGGER=/tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress  touch "$TRIGGER"  trap 'rm -f "$TRIGGER"' EXIT  # Find the newest CLT label  CLT=$(softwareupdate -l 2>/dev/null \    | grep -o 'Label: Command Line Tools for Xcode.*' \    | sed 's/^Label: //' \    | sort -V | tail -1)  if [[ -z "$CLT" ]]; then    fail "No CLT package found in softwareupdate catalog."    suggest "xcode-select --install"    exit 1  fi  todo "Installing: $CLT"  info "Needs sudo — no GUI dialog."  sudo softwareupdate -i "$CLT" --verbose  if xcode-select -p >/dev/null 2>&1; then    ok "Installed: $(xcode-select -p)"    info "$(clang --version 2>/dev/null | head -1)"    info "$(git --version 2>/dev/null)"  else    fail "Install failed."    exit 1  fifiZSH

2Read the result

  • Already installed: it prints the xcode-select -p path and the clang and git versions. You're done.
  • Not installed: it picks the newest "Command Line Tools for Xcode" from softwareupdate -l and installs it with sudo.
  • Nothing in the catalog: it stops. Run xcode-select --install to get Apple's dialog instead.
Source: apps/26.9/script-runner1/data/scripts/setup/ in s7, with the output helpers inlined so it runs on an empty Mac.
