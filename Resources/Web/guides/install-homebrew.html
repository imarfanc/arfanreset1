Install Homebrew

Two pastes: the brew.sh installer, then one that puts brew on your PATH.

  • needs step 1
  • asks for your password
  • Apple silicon: /opt/homebrew

1Run the installer

It asks for your password, lists what it will do, and waits for Return before downloading.

install1 line
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2Put brew on your PATH

The same lines the installer prints under "Next steps". They add shellenv to ~/.zprofile and load it in this window.

shellenv4 lines
echo >> "$HOME/.zprofile"echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> "$HOME/.zprofile"eval "$(/opt/homebrew/bin/brew shellenv zsh)"source ~/.zshrc

3Check it

  • which brew prints /opt/homebrew/bin/brew.
  • brew doctor lists anything wrong with the install.
  • Pasted step 2 twice? ~/.zprofile now has the line twice. Harmless; delete one if you like.
Source: brew.sh. An Intel Mac installs to /usr/local, which is already on the PATH, so skip step 2 there.
