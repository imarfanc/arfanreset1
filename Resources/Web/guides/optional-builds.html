2Install build prerequisites

Install full Xcode first. The current Git checkout guide requires Xcode 26 and the macOS 26 SDK, plus the Metal Toolchain. Add the required components in Xcode → Settings → Components. Command Line Tools alone are insufficient.

5Build and open Ghostty

The version guard stops if the compiler differs from the checkout requirement. A successful build produces zig-out/Ghostty.app, then opens it. Compilation runs as your user.

Ghostty · ReleaseFast14 lines
bash -e <<'SH'cd "$HOME/tmp1/ghostty"zig_bin="$HOME/.local/bin/zig"required=$(sed -nE 's/.*\.minimum_zig_version = "([^"]+)".*/\1/p' build.zig.zon)actual=$("$zig_bin" version)if [ -z "$required" ] || [ "$actual" != "$required" ]; then  echo "This checkout requires Zig $required; selected compiler is $actual."  echo "Install the matching Zig version before building."  exit 1fiexport PATH="$(brew --prefix gettext)/bin:$PATH""$zig_bin" build -Doptimize=ReleaseFastopen zig-out/Ghostty.appSH
  • This is a local source build; your existing installed Ghostty app is untouched.
  • For the official app instead, use Ghostty downloads.
