Optional CLI tools

Install Go, Zig, or Rust when you need them. These are separate from the five fresh-Mac steps. The downloads below target a native Apple Silicon Terminal.

  • pick the tools you want
  • Go asks for your password
  • Zig and Rust: home folder

1Go

Project · Downloads · Install guide. Downloads the official Go 1.27.1 arm64 package, verifies its checksum, then installs it into /usr/local/go. It asks for your password.

2Zig

Project · Downloads · Documentation. Pins Zig 0.16.0 for the Ghostty checkout in your error log. Installs into your home folder and puts ~/.local/bin first on your zsh login PATH.

Zig 0.16.0 · aarch6418 lines
bash -e <<'SH'[ "$(uname -m)" = arm64 ] || { echo "Use a native Apple Silicon Terminal for this download."; exit 1; }work_dir=$(mktemp -d)trap 'rm -rf "$work_dir"' EXITcd "$work_dir"curl -fL --retry 3 -o zig.tar.xz https://ziglang.org/download/0.16.0/zig-aarch64-macos-0.16.0.tar.xzprintf '%s  %s\n' b23d70deaa879b5c2d486ed3316f7eaa53e84acf6fc9cc747de152450d401489 zig.tar.xz | shasum -a 256 -c -mkdir -p "$HOME/.local/opt" "$HOME/.local/bin"if [ ! -e "$HOME/.local/opt/zig-aarch64-macos-0.16.0" ]; then  tar -xf zig.tar.xz -C "$HOME/.local/opt"filn -sfn "$HOME/.local/opt/zig-aarch64-macos-0.16.0/zig" "$HOME/.local/bin/zig"path_line='export PATH="$HOME/.local/bin:$PATH"'touch "$HOME/.zprofile"grep -qxF "$path_line" "$HOME/.zprofile" || printf '%s\n' "$path_line" >> "$HOME/.zprofile"export PATH="$HOME/.local/bin:$PATH"zig versionSH
  • Already have Zig 0.17 in /opt/zig? This installs 0.16.0 alongside it. Your existing installation stays available at /opt/zig/zig.
  • Open a new Terminal after installation. Expected zig version: 0.16.0. The build page uses the new compiler by its full path so an older PATH cannot select 0.17.
  • Apple Silicon uses aarch64-macos. If a project requests another version, use its requirement and the matching download rather than the newest development build.

3Rust

Project · Install guide · rustup guide. Follow the installer prompts; the default installs Rust, Cargo, and rustup in your home folder.
