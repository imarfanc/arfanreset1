Set macOS defaults

78 Finder, keyboard, Dock, screenshot, Mission Control and zoom settings in one paste. It reads each value, writes it, and reads it back, so the output shows what changed.

  • needs Deno (step 2)
  • Full Disk Access for zoom
  • restarts Finder and the Dock
  • undo: defaults delete

1Preview with Check only

Pick Check only, copy, paste. You get a table of current and wanted values. Nothing is written.

2Apply

Switch back to Apply, copy, paste. At the end it asks Log out now? [Y/n]. Keyboard and zoom changes need the new login.
