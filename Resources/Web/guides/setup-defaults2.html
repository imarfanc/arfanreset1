Step 5 of 5

Trackpad and Accessibility

Three small scripts, one setting each. Each quits System Settings first, because it caches panes. Then it writes the setting and prints a before-and-after table.

  • needs uv (step 3)
  • Full Disk Access for 2 and 3
  • no password
  • undo: defaults delete

1Mission Control gesture off

Turns off the three- and four-finger swipe up, and with it App Exposé's swipe down. The Dock restarts so it applies now.

2Trackpad zoom gesture on

Turns on "Use trackpad gesture to zoom". Double-tap with three fingers toggles zoom; double-tap and drag changes the level.

3Accessibility Keyboard on

Turns on the Accessibility Keyboard. The bottom-right dwell corner becomes "Hide / Show Home Panel", the other three corners go off, and dwell time drops to 0.25 seconds.

uv run --with rich python3 - <<'PY'"""Turns on Accessibility → Keyboard → Accessibility Keyboard, with its dwell settings."""import subprocessimport sysfrom rich.console import Consolefrom rich.panel import Panelfrom rich.table import TableCHECK = "--check" in sys.argvDOMAIN = "com.apple.universalaccess"# Corner keys 0–3; action 1 is Hide / Show Home Panel, 0 is none.
