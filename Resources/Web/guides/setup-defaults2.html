Trackpad and Accessibility

Three small scripts, one setting each. Each quits System Settings first, because it caches panes. Then it writes the setting and prints a before-and-after table.

  • needs uv for these scripts
  • Full Disk Access for 2 and 3
  • no password
  • reset to system default: defaults delete
Start here
  1. Install uv first. The app’s CLI tools page has it.
  2. Pick the one change you want below, copy its script and paste it into Terminal.

Steps 2 and 3 need Full Disk Access for Terminal. These scripts save no backup. For backups and restore, use Accessibility & gestures in the app.

1Mission Control gesture off

Turns off the three- and four-finger swipe up, and with it App Exposé's swipe down. The Dock restarts so it applies now.

Open Trackpad settings ↗
mission-control-off.py73 lines
uv run --with rich python3 - <<'PY'PY
  • Pane still shows the old choice? Log out and back in. The trackpad driver reads these at login.
  • Undo: pick "Swipe Up with Three Fingers" in the pane, or set WANT = "2" and paste again.

2Trackpad zoom gesture on

Turns on "Use trackpad gesture to zoom". Double-tap with three fingers toggles zoom; double-tap and drag changes the level.

  • Needs Full Disk Access for Terminal: System Settings, Privacy & Security, Full Disk Access. Or flip the switch in the Zoom pane by hand.

3Accessibility Keyboard on

Turns on the Accessibility Keyboard. The bottom-right dwell corner becomes "Hide / Show Home Panel", the other three corners go off, and dwell time drops to 0.25 seconds.

  • Needs Full Disk Access, same as step 2. "Panel follows hide/show home panel" is on by default and stays that way.
Keys read from this Mac's own defaults. To find the key behind another toggle, run the macOS defaults script (setup-defaults.ts) with --watch <domain>.
