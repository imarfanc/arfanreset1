Optional · Shell setup

Faster zsh startup

Keep Deno, Bun, pnpm, nvm, and uv ready without loading the heavy parts every time you open a shell. Back up your .zshrc, add the setup, then measure.

  • backs up .zshrc
  • no sudo
  • nvm on first use
  • completions on first Tab

1What changes

The expensive parts run when you use them. Startup sets paths and defines small shell functions; it does not start Node, call nvm, or generate completion scripts.

  • Completions: register fpath before compinit. First Tab loads cached completions; subsequent Tab presses use the normal zsh widgets.
  • nvm: first nvm, node, npm, npx, or corepack loads it once. NVM completion loads only when both nvm and the completion system are ready.
  • Bun: its existing ~/.bun/_bun is autoloaded through fpath when needed.
  • PATH: keep entries unique, including pnpm's current PNPM_HOME/bin and older PNPM_HOME layout. Deno and uv get their standard binary directories directly.
  • Small overhead, not a zero-time guarantee. First Tab and the first Node command pay the deferred initialization cost. Other plugins, prompts, .zprofile, and system startup files can still add time.
  • For a plain new-Mac zsh setup. If you already use a framework that defines compdef, its completion system and Tab bindings stay in charge.

  • Your pasted block: the complete Shell Completions … end section is replaced. Recognized standalone eager nvm/compinit lines are commented out, with their original text kept. Other settings are preserved.
  • Custom startup code: multiline loader blocks and framework/plugin configuration stay untouched. If they still load nvm or run compinit early, inspect them to get the intended startup benefit.
  • Node default: the first Node command uses nvm's default alias. If no default is installed, run nvm install 26 && nvm alias default 26. Use nvm use yourself for a project's .nvmrc.
  • Global npm commands and env node scripts need Node on PATH. Run nvm use default once in that shell before launching them directly.

3Generate completions once

Optional: after Deno and uv are installed, save their completion files here. Repeat after tool upgrades. This runs now, never on shell startup. Bun uses the completion file its installer provides.

If startup stays slow, look for old nvm loaders, completion generation with eval, or prompt/plugin initialization elsewhere in your startup files. This setup cannot remove costs imposed by unrelated code.

6Undo if needed

Backups are timestamped files inside ${ZDOTDIR:-$HOME}/backups/, for example ~/backups/.zshrc.backup-20261002-090000-abc123. A backup is made when an existing configuration changes; rerunning an unchanged setup creates no extra backup. The installer prints the exact path. Restore that file to your .zshrc and open a new Terminal. You can also remove the section between reset1 fast shell markers and uncomment lines prefixed reset1 deferred:.

To restore the printed backup, run cp -p "PASTE_BACKUP_PATH_HERE" "${ZDOTDIR:-$HOME}/.zshrc". Review the path first if you have made other shell changes since setup.
